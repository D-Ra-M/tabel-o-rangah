# Табель о рангах

Веб-приложение (PWA) для таблиц оценок и рейтингов: ученики/участники, оценки 5–1, опоздания («О»), пропуски («Н»), автоматический подсчёт баллов и мест. Работает офлайн, данные хранятся только на вашем устройстве.

## Возможности

- Несколько таблиц, переименование, перетаскивание, групповое удаление.
- Баллы: 5 → +10, 4 → +8, 3 → +5, 2 → −1, 1 → −2, «О» → −1, «Н» → −2. Строки сортируются по баллу; **равные баллы делят место** (1, 2, 2, 4), медали получают места 1–3.
- Фото: сжимается до превью 400 px (JPG, PNG, WebP, AVIF, GIF, HEIC/HEIF). Кнопка «Сжать фото» уменьшает фото, добавленные в старых версиях.
- Экспорт/импорт таблицы (JSON), полная резервная копия, автоматическая суточная копия и кнопка «Восстановить».
- Установка как приложение, работа без интернета, синхронизация между открытыми вкладками.

## Публикация на GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)`. Сборка не нужна.

## Разработка

```bash
npm install
npm run serve        # http://localhost:8080
npm run verify       # линтер + проверка проекта + модульные тесты
npx playwright install chromium
npm run test:e2e     # сквозные проверки в Chromium
```

Структура:

| Путь | Назначение |
|------|-----------|
| `index.html`, `css/styles.css` | разметка и стили |
| `js/logic.js` | чистая логика: баллы, места, очистка данных (покрыта тестами) |
| `js/storage.js` | IndexedDB: отдельная запись на таблицу, миграция, суточная копия, синхронизация вкладок |
| `js/ui.js` | уведомления и модальные окна (доступность, фокус) |
| `js/photo.js` | подготовка фото и вызов конвертера HEIC |
| `js/app.js` | основной код приложения |
| `vendor/` | SortableJS 1.15.6, heic2any 0.0.4 (с лицензиями) |
| `service-worker.js` | офлайн-кэш |

**При изменении любого файла из `APP_SHELL` увеличьте `VERSION` в `service-worker.js`.**

## Безопасность и конфиденциальность

- Строгая Content-Security-Policy: только собственные скрипты и стили, без inline-кода и `eval`.
- Нет внешних запросов и CDN: все библиотеки лежат в `vendor/`.
- HEIC конвертируется в изолированном `sandbox`-iframe: библиотеке не доступны данные приложения.
- Данные импорта проходят очистку (длины, форматы, допустимые типы фото).
- Все данные остаются в браузере пользователя; приложение ничего никуда не отправляет.

> Если приложение используется в организации (школе, секции) для данных других людей, особенно детей, то имена, оценки и фотографии являются персональными данными (152-ФЗ). Нужны правовое основание обработки и согласия. Для личного использования закон не применяется.
